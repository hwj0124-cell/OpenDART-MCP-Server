# 기업저축 vs 가계저축: 순자금운용·경상수지 반응의 체계적 차이 (OECD 패널)

「반도체發 경상수지 흑자 확대와 IMF 대외부문평가 대응 방향」 Ⅲ-2(흡수 시차)의 주장
— *기업저축 증가가 주도한 흑자는 배분·지출 과정에서 시차를 두고 축소되는 반면,
저축성향 변화에 따른 가계저축 증가는 그렇지 않다* — 을 OECD 제도부문별 계정으로 검증한다.

## 실행

```bash
pip install pandas numpy matplotlib requests
python fetch_oecd.py          # sdmx.oecd.org 접속 필요 → data/raw/*.csv
python build_panel.py         # → data/panel.csv (국가×연도, GDP 대비 %)
OMP_NUM_THREADS=1 python run_analysis.py --reps 499   # → output/
```

## 방법

| 구분 | 내용 |
|---|---|
| 자료 | OECD 비금융 부문계정(연간): S1·S11·S12·S13·S14_S15의 B9(순대출), B8G(총저축), B6G, B2G_B3G, D42, D5, P51G, P3 |
| 경상수지 | 국민경제 순대출(S1 B9, 없으면 −S2 B9) ≈ 경상수지 + 자본수지 |
| 충격(기본) | 비금융법인 총저축/GDP 변화 vs 가계 총저축/GDP 변화 — 두 충격을 동시에 투입 |
| 충격(대안) | 비금융법인 총영업잉여/GDP 변화(**기업이익**) vs 가계 총저축률 변화(**저축성향**) |
| LP | y<sub>t+h</sub>−y<sub>t−1</sub> = α<sub>i</sub> + δ<sub>t</sub> + β<sup>c</sup>x<sup>c</sup> + β<sup>h</sup>x<sup>h</sup> + 통제(2시차 Δ부문저축·ΔCA·성장률, 직전 수준) ; 국가·연도 FE, 국가 군집 SE |
| 전가율 | LP-IV. ① 충격시점 부문저축 1%p당 h기 CA 반응, ② 0~h기 누적 CA / 누적 부문저축 (누적 전가율) |
| 검정 | 단기(h=0~1)→중기(h=4~6) 전가율 하락폭의 기업−가계 차이, 국가 블록 부트스트랩 |
| 에피소드 | 한 부문저축 변화가 상위 10%이고 다른 부문은 중위수 이하인 해. 연도평균 제거 사건연구 + 에피소드 더미 LP |
| 경로 | 기업충격 후 배당·법인세 지급, 기업투자, 가계·정부 순대출, 가계소비 반응 |
| 강건성 | 2020–21년 제외, 당기 성장률 통제, 대안 충격 정의 |
